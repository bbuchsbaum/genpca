# Print an sfpca fit

Prints a one-line summary of an
[`sfpca`](https://bbuchsbaum.github.io/genpca/reference/sfpca.md)
object: number of components, dimensions, and singular values.

## Usage

``` r
# S3 method for class 'sfpca'
print(x, ...)
```

## Arguments

- x:

  An `sfpca` object.

- ...:

  Ignored.

## Value

`x`, invisibly.
